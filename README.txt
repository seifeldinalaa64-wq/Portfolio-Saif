Open index.html in a browser (internet needed for Bootstrap, Tailwind and Google Fonts CDNs).
All files live in this single folder (no subfolders).
Edit content in index.html / script.js, styles in style.css, photo in me.jpeg.
Certificate images must be named like the slug of the title (lowercase), e.g. business-ethics-game.jpeg.

Social icons link to #contact: replace them in script.js (search "LinkedIn").

Contact form: uses FormSubmit (formsubmit.co). The FIRST message sent after publishing the site triggers an activation email to seifeldimalaa64@gmail.com - click "Activate" once, then all messages arrive in the inbox.
If sending fails, the form offers a mailto fallback.
